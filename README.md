# BiznesOS

Kichik savdo nuqtalari uchun brauzerda ishlaydigan ombor va savdo hisobi prototipi.

## Hozirgi imkoniyatlar

- Mahsulot nomi, narxi va ombordagi miqdorini kiritish.
- Sotuvni qayd etish va sotilgan miqdorni ombordan avtomatik ayirish.
- Omborga qo‘shimcha mahsulot qabul qilish.
- Mahsulotni o‘chirishdan oldin tasdiq so‘rash.
- Savdo tushumi va sotuvlar tarixini ko‘rsatish.
- Kam qolgan mahsulotlar uchun ogohlantirish.
- Miqdor va narx maydonlarini tekshirish.
- Mahsulotlar va sotuvlarni brauzerning `localStorage` xotirasida saqlash.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki GitHub Pages orqali joylashtiring. Build vositasi va API kaliti talab qilinmaydi.

## MVP chegaralari

Bu hali ko‘p foydalanuvchili buxgalteriya yoki POS tizimi emas. Ma’lumotlar faqat joriy brauzerda saqlanadi; server sinxronlash, xodim rollari, fiskal chek, bank integratsiyasi va buxgalteriya eksporti yo‘q.

## Keyingi bosqich

Kunlik/oylik hisobotlar, CSV eksport, mahsulot kategoriyalari, xarajatlar hisobi va xavfsiz server bazasi.
